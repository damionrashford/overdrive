# Changelog

## 1.1.0

First public release.

- Monitoring: CPU per core by cluster, memory pressure, GPU, storage with purgeable space, network, battery charge power and health, SMC temperatures, fans and system power (direct edition).
- History at 3-minute, 1-hour and 24-hour ranges.
- Menu bar readout with text or live graphs and a mini dashboard.
- Alerts for sustained CPU load, memory pressure, low disk space, CPU temperature and low battery.
- Cleanup of caches, logs, developer junk, the Trash and stale downloads with per-item review and an ignore list.
- Storage map (treemap) with folder drill-down.
- Large file finder.
- Uninstaller with leftover detection across Library folders.
- Startup items from launchd, with enable/disable in the direct edition.
- AI workloads: runtime detection, loaded models via Ollama and LM Studio loopback APIs, model libraries on disk, orphaned Ollama blobs, memory headroom estimate.
- Processes with energy and disk I/O columns (direct edition) and a details bar.
- Maintenance tasks: free memory, reclaim purgeable space, empty Trash, flush DNS, reset Quick Look, repair Launch Services, restart Dock and Finder, rebuild Spotlight, delete old simulators, Homebrew cleanup.
- Light and Dark Mode, VoiceOver labels, Reduce Motion.
- App Store (sandboxed) and direct (notarized) editions from one codebase.
